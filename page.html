LangChain & LangGraph Learning Overview

Phase 1 Study & Concept Breakdown

1. LangChain Core Concepts

  • LLMs & Chat Models: Standardized interfaces for interacting with various language models.
  • Prompt Templates: Structured formatters to build dynamic prompts programmatically.
  • Output Parsers: Extract structured data (JSON, XML, Pydantic objects) from raw LLM responses.
  • Chains & LCEL: LangChain Expression Language allows chaining models, prompts, and parsers using pipe syntax.

2. LangGraph Concepts

  • Stateful Multi-Agent Orchestration: Used to model agent workflows as cyclic graphs rather than simple linear chains.
  • Nodes & Edges: Nodes represent python functions/tools, and Edges control execution flow based on output.
  • State Management: Maintains continuous memory/context across steps for multi-step tasks.
  • Human-in-the-Loop: Allows pausing execution for manual approval or feedback.

3. Key Takeaways & Resources

LangGraph is essential for building robust orchestrator agents where cycles, state persistence, and fine-grained control over execution steps are required.
