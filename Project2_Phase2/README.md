# Project 2 - Phase 2: LangGraph Retail Data Pipeline

An automated data engineering and analysis pipeline built using **Python**, **LangChain**, and **LangGraph**. The pipeline ingests local retail sales data, cleans nulls and duplicate records using Pandas, queries a Groq-hosted LLM (`qwen/qwen3.6-27b`) for executive insights, and visualizes sales distribution across independent subplots using Matplotlib.

---

## 🏗️ Architecture & Graph Flow

The pipeline is implemented using LangGraph's `StateGraph` pattern (`State` -> `Node` -> `Edge`):
[START] ──> (Cleaner Node) ──> (Analyzer Node) ──> (Visualizer Node) ──> [END]

### **1. Shared State Schema (`PipelineState`)**
* `csv_path` (*str*): System path to the target dataset.
* `cleaned_df` (*Optional[pd.DataFrame]*): In-memory DataFrame after execution of cleaning rules.
* `summary_text` (*Optional[str]*): Executive summary string generated by the Groq LLM.

### **2. Agent Nodes**
* **Cleaner Node (`clean_data_node`)**: Loads `retail_sales_dataset.csv`, removes duplicate rows, and replaces missing values (`NaN` -> `0`).
* **Analyzer Node (`analyze_data_node`)**: Queries the Groq API via `langchain-groq` (`qwen/qwen3.6-27b`) to generate a 2-sentence executive overview of dataset dimensions.
* **Visualizer Node (`visualize_data_node`)**: Renders a 3-panel Matplotlib figure displaying total revenue, price distribution, and purchase item counts on independent axes.
